================================================================================
                            DATA FLOW SUMMARY
================================================================================

INPUT:  PCAP file + Ground Truth CSV
        │
        ├─→ [REPLAY] Extract flows, add labels, send to Kafka
        │
        ├─→ [FEATURE ENGINE] Calculate CICIDS65 features
        │
        ├─→ [ML CONSUMER] 5 models vote on each prediction
        │
        └─→ [CSV LOGGING] Save all predictions + ground truth
                          
OUTPUT: predictions.csv
        │
        └─→ [METRICS] Calculate accuracy, precision, recall, F1
                      Per-attack-type metrics
                      Confusion matrix
                      Confidence calibration
                      Model agreement analysis
                      │
                      └─→ metrics.json + confusion.png
