# Quick Reference: X520 DPDK Testing Commands

## One-Time Setup (When X520 Arrives)

```bash
# 1. Check if X520 recognized
lspci | grep -i "ixgbe\|Intel.*Ethernet"

# 2. Load ixgbe driver
sudo modprobe ixgbe

# 3. Load DPDK UIO driver
sudo insmod /lib/modules/$(uname -r)/kernel/drivers/uio/igb_uio.ko

# 4. Bind X520 to DPDK (replace PCI address as needed)
sudo dpdk-devbind.py -b igb_uio 0000:02:00.0

# 5. Verify binding
sudo dpdk-devbind.py --status
```

## Standard Testing Workflow

### Terminal 1: Start Pipeline
```bash
cd /home/ifscr/SE_02_2025/IDS
sudo bash run_realtime_engine_dpdk.sh start
```

### Terminal 2: Start ML Consumer with CSV Logging
```bash
cd /home/ifscr/SE_02_2025/IDS
source venv/bin/activate
python3 dpdk_suricata_ml_pipeline/src/realtime_ensemble_consumer_with_csv.py \
    --csv-output predictions.csv
```

### Terminal 3: Replay PCAP with Ground Truth
```bash
cd /home/ifscr/SE_02_2025/IDS
source venv/bin/activate
python3 dpdk_suricata_ml_pipeline/src/replay_pcap_for_testing.py \
    --pcap-file dataset.pcap \
    --ground-truth groundtruth.csv \
    --max-packets 50000
```

### Terminal 4: Monitor Progress
```bash
# In real-time while replay is running
tail -f /home/ifscr/SE_02_2025/IDS/logs/ml_consumer.log | grep "Processed:"
```

### Terminal 5: Calculate Metrics (After Replay Completes)
```bash
cd /home/ifscr/SE_02_2025/IDS
source venv/bin/activate
python3 dpdk_suricata_ml_pipeline/src/calculate_accuracy_metrics.py \
    --predictions predictions.csv \
    --output metrics.json \
    --confusion-matrix confusion.png
```

## Troubleshooting Quick Fixes

```bash
# DPDK binding failed
sudo dpdk-devbind.py -b igb_uio 0000:02:00.0

# Kafka not responding
sudo bash dpdk_suricata_ml_pipeline/scripts/02_setup_kafka.sh

# Reset everything
sudo pkill -9 -f "kafka\|suricata\|realtime_\|replay_"
sleep 3
sudo bash run_realtime_engine_dpdk.sh start

# Check logs for errors
grep -i "error\|failed" logs/*.log

# Get line count of predictions
wc -l predictions.csv
```
